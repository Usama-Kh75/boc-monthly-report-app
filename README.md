# التقرير الشهري الموحد — شعبة تبريد المركز

البرنامج: https://usama-kh75.github.io/boc-monthly-report-app/

يُفتح في Edge أو Chrome، ويحوّل تقارير الوحدات الشهرية إلى تقرير الشعبة الموحد.
يمكن تثبيته من المتصفح (زر «تثبيت» في شريط العنوان)، ويعمل بلا إنترنت، ويتحدّث تلقائياً.
ملفات الوحدات والتقارير تُعالَج داخل المتصفح على الحاسبة نفسها ولا تُرفع إلى أي مكان.

إعداد المهندس أسامة خليل هاشم

البصمة الرقمية المعتمدة: `53f2fba6`

تُحسب من قوائم البرنامج والقالب الرسمي وتوقيع المُعِدّ، وتظهر أسفل شاشة البرنامج.
إن ظهرت هناك بصمة غيرها، أو شريط تنبيه أحمر في أعلى الشاشة، فالنسخة معدَّلة عن الأصلية.
